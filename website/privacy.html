PRIVACY

数据边界

Wayfinder 的完整会话、文件变化摘要和航海图保存在你的电脑上。

本地保存

Prompt、回复、工具摘要、验证结果、文件变化摘要和航海图存储在 ~/.wayfinder。当前版本没有账号、遥测、广告或云同步。

自动采集

Wayfinder 在本机读取 Codex、Claude Code 与 TRAE CN 的兼容会话记录，并以增量方式更新航海图。TRAE CN 采集目前为 macOS Early Access，通过运行中应用的本机回环会话服务读取完整消息，不操作界面，也不修改 TRAE 数据库。

规则分析

当前版本只在本地根据测试失败、工具失败、用户否决和回滚等明确证据整理失败候选，不调用云端模型。

网络访问

TRAE CN 采集只连接 127.0.0.1；应用仅在你主动查看版本信息时打开 GitHub Releases。会话内容、文件变化摘要和航迹不会上传到 Wayfinder 服务。

删除数据

卸载应用不会删除历史。需要清除时，请先退出 Wayfinder，再删除 ~/.wayfinder 中对应项目或全部数据。
