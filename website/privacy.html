PRIVACY

Data boundary

Wayfinder keeps full sessions, file-change summaries, and the voyage map on your computer.

Stored locally

Prompts, replies, tool summaries, validation results, file-change summaries, and the voyage map are stored in ~/.wayfinder. The current version has no account, telemetry, advertising, or cloud sync.

Automatic collection

Wayfinder reads compatible Codex and Claude Code session records on your machine and updates the voyage map incrementally.

Rule-based analysis

The current version organizes failure candidates locally from explicit evidence such as test failures, tool failures, user rejections, and rollbacks, without calling a cloud model.

Network access

The app opens GitHub Releases only when you actively check for versions. Session content, file-change summaries, and the voyage map are not uploaded to a Wayfinder service.

Deleting data

Uninstalling the app does not delete history. To clear it, quit Wayfinder first, then delete the relevant project or all data under ~/.wayfinder.
