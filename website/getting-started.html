GETTING STARTED · 0.3.17 EARLY ACCESS

Install Wayfinder and start keeping the project process.

Choose the installer that matches your computer, verify the download, open Wayfinder, then keep using Codex or Claude Code as usual. The app backfills available local history and keeps the project voyage map updated.

1. Choose an installer

Every installer and SHA256SUMS comes from the same public GitHub Release.

2. Verify the download

Download SHA256SUMS from the Release first, then verify the installer. Use shasum -a 256 on macOS or Get-FileHash -Algorithm SHA256 in Windows PowerShell.

Download SHA256SUMS ↗ Open the 0.3.17 Release ↗

3. Complete first launch

The current zero-cost Alpha is not store-signed. On macOS, choose Open Anyway under System Settings → Privacy & Security. Windows may show Microsoft Defender SmartScreen; after verifying the checksum, choose More info → Run anyway.

Wayfinder requires macOS 12 or newer, or Windows 10/11 x64. It does not require a separate Git or Node.js installation.

4. Keep working as usual

Keep Wayfinder running, then continue using Codex or Claude Code. First launch backfills compatible local history; after that, the watcher processes only new or changed session records and groups them by project.

No IDE plugin is required, and you do not need to change your existing workflow.

Local data

Complete history, file-change summaries, collection cursors, and voyage maps stay under ~/.wayfinder. The current version has no account, telemetry, cloud sync, or cloud analysis.

Uninstalling the app does not automatically delete history. To clear data, quit Wayfinder first, then delete the relevant project or all content under ~/.wayfinder.
