RELEASE HISTORY

Wayfinder updates and release history.

This page records public changes that users can verify. The current installable version is 0.3.17 Early Access for Apple Silicon, Intel macOS, and Windows x64.

0.3.17 · 2026-09-14

Current public release. The public desktop app collects Codex and Claude Code history only.

  • Published Apple Silicon, Intel macOS, and Windows x64 installers with SHA256SUMS.
  • Added pages for AI collaboration history, Codex, Claude Code, factual comparison, and data boundaries.
  • Added structured data, llms.txt, complete sitemap coverage, clean canonical URLs, and a real HTTP 404.
  • Strengthened rejection of generic waypoint titles so project paths remain scannable.

Withdrawn releases

The 0.3.15 and 0.3.16 Release pages remain as historical records, but their install assets and old checksums were removed. They are not supported download paths; use 0.3.17.

0.3.14 · 2026-09-12

  • Desktop collection no longer required system Git and stopped creating workspace snapshots.
  • Kept the currently displayed project selected until a requested project finished loading.
  • Hardened session rewrites, truncation, archive migration, and file-change truthfulness.

0.3.13 · 2026-09-12

  • Added first-launch backfill for available local Codex and Claude Code history.
  • Kept compatible sessions without a project folder in a local general-collaboration project.
  • Kept stable deduplication when sessions moved into archive locations.

0.3.12 · 2026-09-12

  • Hardened collection, locks, paths, state writes, and release gates across macOS and Windows.
  • Required successful CI, public checksums, and the latest main commit before public deployment.
  • Fixed narrow-window actions, keyboard focus, search framing, and stale project requests.
