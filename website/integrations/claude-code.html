CURRENT COLLECTOR · CLAUDE CODE

把 Claude Code 的多轮工作放回同一张图。

Wayfinder 在本地读取兼容的 Claude Code 会话，按工作区与目标组织航程，让不同尝试、分支和验证不再散落在独立聊天中。

适合回看什么

  • 一个项目在多个 Claude Code 会话之间如何继续。
  • 哪些实现方向失败、回退或被用户否决。
  • 工具活动与文件编辑来自哪个原始回合。
  • 最终方案经过了哪些测试或验证。
  • 不同 AI 工具围绕同一目标产生的相关工作。

本地边界

采集、归并和地图生成在本地完成。Wayfinder 不要求 Claude Code 安装插件，也不向 Wayfinder 服务上传完整会话、文件变化摘要或航海图。

只有来源记录中真实成功的编辑才会形成文件变化；应用不会根据当前工作区补造过去没有留下证据的 Diff。

开始使用

打开 Wayfinder 后继续正常使用 Claude Code。首次启动会导入本机可用历史，随后 watcher 只处理新增或变化的会话记录。
